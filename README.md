# Site de casamento (Fase 1)
1. Suba esta pasta para um repositório no GitHub (branch `main`).
2. Em Settings > Pages, escolha "GitHub Actions" como fonte.
3. Coloque a foto do casal em `public/foto-casal.jpg`.
4. Edite os textos em `src/content.js` (na Fase 2 isso passa para o painel admin).
Local: `npm install && npm run dev`.
